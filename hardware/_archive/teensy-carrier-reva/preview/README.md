# Assembled-view preview / simple handoff

The original `board-top.png` is a **technical copper/silkscreen plot**, not an
assembled-board picture. Use **`../ASSEMBLED-PREVIEW.png`** for the assembled view.

`render.py` uses the actual routed PCB as the base. KiCad stock VRML models supply
ordinary connectors/passives. The Teensy plus sockets, Pololu module and unavailable
fuse model use **simplified illustrative geometry**, not exact vendor internal
component layouts. Module models must NOT be used for mechanical fit checking.
Colours are illustrative. This is a rendering, not a photograph or evidence of
successful fabrication, electrical operation, or thermal qualification.

The script writes a **render-only copy** under this directory and does not modify
the manufacturing PCB, nets, Gerbers, or firmware. It requires KiCad 9, Python
pcbnew and Pillow. Run `/usr/bin/python3 preview/render.py` from the carrier folder.

Stock model sources:
`https://raw.githubusercontent.com/KiCad/kicad-packages3D/master/<library>.3dshapes/<part>.wrl`
The downloaded files are preserved locally in `models/`, with their original
copyright/license headers. See `models/LICENSE-KICAD.md` and the individual files.
Custom illustrative modules are generated by render.py. The standard KiCad library
exception permits using its geometry in designs/rendered outputs; no vendor is
claiming this prototype is validated.

`package.py` creates `../simple/` with just:
- `PCB-FILES.zip`: necessary fabrication layers/drills, component lists and safety/
  fabrication notes. No redundant drill-map PDFs or editable CAD files.
- `ASSEMBLED-PREVIEW.png`: the assembled 3D presentation.

It also copies those two files to `/home/chris/Downloads/Racecar-Board-Simple/`.
Separate Gerber layers cannot simply be discarded to reduce file count. The ZIP
is the single uploadable container; its files describe different physical layers.
The earlier complete CAD archive remains available for an engineer's review.
